# Udhaar — Plain-Language & Wording Changes Guide

**Date:** November 4, 2026
**Total Changes / Additions:** 1328

## Style Guide Rules Applied
1. Written for class 6 reading level: short, direct, everyday words.
2. Action buttons start with active verbs.
3. Complete elimination of technical jargon: `hash`, `SHA-256`, `E.164`, `keystore`, `SQLCipher`, `payload`, `token`, `counterparty`, `audit`, `VPA`, `principal`, `amend`, `ledger`, `immutable`, `cryptographic`.
4. All ALL CAPS strings converted to natural sentence case.
5. Polite, respectful reminder drafts without threats or mentions of third parties or legal action.
6. All 5 languages (English, Hindi, Bengali, Assamese, Nepali) synchronized with 0 missing and 0 blank keys.
